# Resume Materi KMReact - Figma Introduction

## 3 Poin penting

### - Figma

Figma merupakan tools yang biasa digunakan oleh desainer untuk mendesain produk dalam bentuk visual seperti User Interface, mockup, prototyping, bahkan desain grafis. Figma dapat berkolaborasi secara real-time bersama tim dan membantu menghubungkan antara Desainer dengan Developer dengan cara menerjemahkan hasil desain menjadi kode program sesuai kebutuhan.

### - Kelebihan dan kekurangan Figma

- Dapat digunakan secara gratis.
- Berkolaborasi dengan tim secara real-time tanpa mengunduh aplikasi desktop.
- Kompatibel dengan berbagai platform device seperti Android, IOS, Windows, Linux, MacOS
- Akses fitur tambahan berbayar.
- Hanya bisa digunakan apabila tersambung dengan jaringan internet.

### - Fitur Unggulan Figma

- Prototype : Membuat desain dapat berinteraksi sehingga terlihat real.
- Comment : Memberikan Feedback dalam bentuk komentar kepada tim yang berguna untuk merevisi desain.
