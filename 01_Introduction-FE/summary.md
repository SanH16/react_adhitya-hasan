# Resume Materi KMReact - Introduction Front-End

### Front-end developer : 
Role pengembang yang men-develop tampilan visualisasi dari suatu produk biasanya akan berinteraksi langsung dan dapat dilihat oleh user, hasil kerja front-end developer terlihat di Client-side serta memiliki kemampuan yang dibutuhkan seperti HTML, CSS, JavaScript dan lain-lain.

### Tugas Front-end Web : 
- Mengubah UI/UX Design yang telah dirancang kedalam suatu website.
- Memastikan User Interface yang telah dibuat sesuai dengan rancangan dan dapat digunakan secara nyaman oleh user.
- Memastikan setiap fungsional seperti gambar, tombol, konten dapat berjalan dengan baik dan tidak menganggu interaksi dengan user.

Susunan URL berisikan protocol, IP Addres / DNS, port, kemudian resource.
protocol : http/https
DNS / IP Address  : localhost / 127.0.0.1
port : 80 atau 8080
resource : index.html

### Memanfaatkan browser Chrome dari sisi Front-end :
1. View page source : Berisikan struktur halaman website seperti html, css, javascript yang ada di halaman tersebut.
2. Inspect  : Melihat kumpulan kode di halaman browser yang berisikan Elements, Console, Source, Network, dan Application. Melihat dan mengatur responsive layar sesuai dimensi yang dipilih. Menggunakan Network untuk melihat isi informasi halaman seperti Name, Status, Type, Intiator, Size, Time. Menggunakan Application Storage yang berfungsi sebagai tempat penyimpanan data sementara dalam membangun sebuah halaman website.

### Hosting :
- Menyimpan file atau website yang telah dibuat kedalam sebuah server untuk membantu menghubungan aplikasi website agar dapat diakses oleh banyak orang hanya dengan menggunakan internet.

### Ilustrasi HTML, CSS, dan JavaScript :
- HTML diilustrasikan sebagai kerangka atau fondasi dari sebuah manusia seperti misal tubuh manusia.
- CSS digambarkan sebagai warna kulit dan pakaian yang menghiasi tubuh manusia tersebut.
- JavaScript berperan sebagai otak yang ada di dalam tubuh manusia yang berfungsi sebagai penggerak dan melakukan banyak hal seperti dalam konteks form validation website yang dapat melakukan validasi input untuk field yang dibuat menggunakan HTML dan dihiasi oleh CSS yang telah dijelaskan sebelumnya.

### Version Control System : Memudahkan melakukan domumentasi saat bekerja secara team dalam membangun proyek.
Git : Berfokus pada proyek pengembangan aplikasi dengan memanfaatkan Command Line (CLI).
GitHub : Sebagai tempat untuk mengakses git yang bisa diakses melalui aplikasi client berbasis website dan desktop.

### Web Security : 
Penggunaan protocol https untuk sekarang lebih baik dari segi keamanan dibandingkan dengan protocol http. 

### Package Manager : 
Tool yang memudahkan pengguna dalam mengatur packet perangkat lunak seperti yarn dan npm. Biasanya digunakan untuk pemasangan, konfigurasi paket, pendeteksi dependensi paket, update paket dan lain-lain. Paket merupakan berkas yang telah dikompilasi agar siap dieksekusi sistem.
